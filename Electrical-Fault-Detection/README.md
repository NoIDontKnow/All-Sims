\# Electrical Fault Detection Simulator



\*\*An interactive tool to learn about electrical fault detection using simulated sensor data.\*\*



!\[App Screenshot](screenshot.png)



---



\## \*\*Project Overview\*\*



This project is a \*\*hands-on learning tool\*\* for understanding how to detect faults in electrical systems using simulated sensor data. It helps you practice:

\- Simulating electrical signals (voltage and current).

\- Setting and adjusting thresholds for fault detection.

\- Visualizing and analyzing faults in real-time.



---



\## \*\*What You Will Learn\*\*



✅ \*\*Data Simulation\*\*

Model realistic electrical sensor data with noise and faults.



✅ \*\*Fault Detection Basics\*\*

Use threshold-based algorithms to identify voltage spikes and current anomalies.



✅ \*\*Data Visualization\*\*

Plot and interpret time-series data to spot issues.



✅ \*\*Technical Documentation\*\*

Document your findings and improve your technical writing skills.



---



\## \*\*How It Works\*\*



1\. \*\*Simulated Data:\*\*

&nbsp;  The app generates synthetic voltage and current data, including random noise and intentional faults (spikes/drops).



2\. \*\*Fault Detection:\*\*

&nbsp;  You set thresholds for voltage and current. The app highlights any values outside these thresholds as faults.



3\. \*\*Interactive Exploration:\*\*

&nbsp;  Adjust the thresholds to see how they impact fault detection. Download the data for further analysis.
